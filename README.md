 This project demonstrates the practical use of Bash scripting concepts, including loops, conditional statements, functions, user input handling, and file management. It is designed as a beginner-friendly project for learning how Linux shell scripting can be used to automate and manage data from the terminal.

# Features

1) Add new student records
2) Search students by Roll Number, Name, or Class
3) View all stored student records
4) Remove a student record using Roll Number
5) Menu-driven interface for easy interaction
6) Data stored in a simple text file

# Technologies Used

1) Linux Terminal
2) Bash Scripting
3) Text File Storage
4) Basic Linux Commands
5) Purpose of the Project

The main purpose of this project is to practice Linux and Bash scripting skills while building a simple data management system that runs completely in the terminal environment.
